ai-agent-demo — Developer's Guide

A from-zero technical walkthrough of the ServiceNow GRC Replication Platform — written for a ServiceNow developer who has never written Python, used a terminal, or touched React.

FastAPI + SQLAlchemy backend Next.js + React frontend Zero prior tech-stack knowledge assumed

This project rebuilds a slice of ServiceNow's GRC: Risk Management module — Risks, Controls, Issues, Assessments — as a standalone web app, so every piece ServiceNow normally builds for you automatically (a table, its REST API, its list view, its audit trail) is instead built and visible by hand. This guide walks through all of it, assuming only that you already know ServiceNow — nothing else.
